# ADR-0002: 仅免费版——无云端、无 Pro、无 License

- 状态：已接受
- 日期：2026-09-09

## 背景

参考项目 wp-plug 的完整设计是双版本制：免费版本地闭环 + 付费版接 Rust 云端（License Key、mTLS、跨站威胁情报、云端 ML 归因）。greenpng 立项时明确：只做免费版插件，不含付费功能与云端服务器系统；第三方 API（站长自填凭据）在范围内。

## 决策

1. greenpng 永久只有免费版，发布渠道为 WordPress.org。
2. 代码与 UI 中**禁止**出现 Pro/premium/license/cloud/upgrade 语义的功能开关、灰化占位与升级文案。
3. 参考项目中全部云端耦合元素**删除而非禁用**：License 校验、云端遥测端点、mTLS、跨站布隆过滤器下发、`cloud_synced` 列、云端存储三模式、P38 云端授权页。
4. 站长自填凭据的第三方 API（GA4/Meta CAPI/Turnstile/AbuseIPDB 等）不属于"云端"，允许，但默认关闭且 readme 披露。

## 后果

- 正面：架构大幅简化（无端云双轨、无熔断云端、无授权心跳）；天然满足 WP.org 零外呼铁律；无"代码里埋休眠外呼"的审核风险。
- 代价：放弃跨站威胁情报与云端算力类功能（随机森林行为熵、马尔可夫归因、跨站 ID 对齐）。这些功能在 PHP+MySQL 下本就不可行，放弃无实际损失。
- 注意：免费版功能不得人为阉割（无额度/数量限制），与 WP.org 对试用版的态度保持一致。
