# ADR-0007: 通用化集成、四支柱首发、隐私双轨与 MySQL-only

- 状态：已接受
- 日期：2026-09-09
- 关联：细化 0005（隐私改双轨）；修订 0006 第 3/6 条（SQLite 兼容目标取消）；0002/0003 维持不变（免费定位、PHP 7.4/WP 6.0 基线不变，新增向上防御要求）
- 依据：`iss/` 同事审计报告 11 份（评审结论见 `docs/14`）+ 站长 2026-09-09 八项决策（OQ-1~4 + 安全 IP + 访客身份 + 任务队列 + v1.0 范围）

## 背景

同事对 greenpng 规划文档做了全面审计（iss/ 目录），站长随后对其中争议点逐一拍板。本 ADR 记录全部决策，供后续代码实现遵循。评审中对 iss/ 报告的关键事实核验记录见 `docs/14` §1（含两处不实引用与多处过时论断的更正）。

## 决策

1. **通用化集成原则（与铁律同级，AGENTS.md 铁律 6）**：生态适配器只通过目标插件的公开 Hook / 公开 API 挂接；禁止对目标插件做版本号锁定、禁止以"代码样本匹配/样本库"方式检测或适配插件；目标插件升级导致 Hook 漂移时须有回退 Hook 与状态页告警，不得静默失效；优先使用 WordPress 核心层机制（REST、钩子、meta API）而非目标插件内部实现。
2. **v1.0 四支柱首发**：客户端安全探针（默认开）、落地页 A/B 测试、CAPI 出网（Meta/GA4，opt-in）、GeoIP 开箱预置（DB-IP Lite），全部进入 v1.0；路线图重排见 `docs/12` 修订版。
3. **隐私双轨**：
   - 安全轨（安全日志、封禁、探针信号）：依 GDPR 合法利益（Recital 49）处理完整 IP 与自动化环境信号；后台展示默认脱敏；提供匿名化开关（默认关闭=完整存储）；readme 披露依据。
   - 营销轨（归因、行为、CRM）：维持 ADR-0005 同意门控与 IP 匿名化。
   - 桥接规则：安全**结论**（布尔疑似标记 + 分数档位）可通过事件通道进入 CRM 打标（`sys:suspected_bot`），**原始安全信号与指纹明细永不写入联系人画像**。
4. **MySQL-only**：只承诺 MySQL / MariaDB（WordPress.org 生态主流安装面）；不做 SQLite 方言兼容承诺；浪涌折叠等写入使用 MySQL 原生 `INSERT ... ON DUPLICATE KEY UPDATE`。`:8090` SQLite 站降级为参考环境（ADR-0006 第 3 条中"次要兼容环境"表述废止）。
5. **版本基线统一（向下兼容 + 向上防御）**：最低支持线 WP 6.0 / PHP 7.4 / MySQL 5.7，向上兼容至 PHP 8.5+ / WP 7.1+。不针对特定版本写分支，只做能力检测（如 HPOS）。向上防御规范（动态属性纪律、内部函数 null 防御、JIT i18n）见 `docs/04` 修订。若 WP 6.0 兼容成本被证实过高，可经复审上调下界（触发条件记录于本 ADR）。
6. **自适应任务队列**：`Gr_Queue` 门面在运行时嗅探 Action Scheduler（宿主已有则使用其重试与并发锁，如 WooCommerce 站点），否则回落 WP-Cron + transient 互斥锁（TTL 300s）+ 状态页真实 cron 引导。**不打包** Action Scheduler（其许可证为 GPLv3，实读自 woocommerce/packages/action-scheduler/license.txt；不分发则无许可问题；GPLv2+ 项目引入 GPLv3 代码须整体转 v3，无此必要）。
7. **测试矩阵覆盖站长常用插件**：WooCommerce（HPOS 开/关 × 经典/Blocks 双结账）、Contact Form 7、Fluent Forms、WPForms、Elementor、主流缓存插件、主流 SEO 插件的共存测试纳入 `docs/11`/`docs/13`。
8. **独立 Settings 页**：顶级菜单下设立独立全局设置页（General / Security / Attribution 标签），`docs/06` 页面数 19 → 20。页面数上限解除（信息架构服从功能），去重纪律保留。

## 后果

- 正面：v1.0 兑现全部核心用户诉求（RPA 识别、归因、A/B、开箱体验）；任务可靠性不再受 WP-Cron 伪定时拖累；GeoIP 开箱即用；安全封禁功能完整可用；合规口径与行业惯例（安全场景完整 IP）一致。
- 代价：v1.0 交付量显著增大（`docs/13` 任务集由 61 项扩至 85 项，四支柱并行推进）；探针默认开需要谨慎的披露措辞（`docs/08` 增列自查项）；DB-IP Lite 数据文件（约 4MB）随仓库维护并在 readme/NOTES 做归属声明；失去 SQLite 环境承诺（该环境用户群不在目标内）。
- 复审触发点：WP 6.0 兼容成本过高时上调下界；探针默认开引发审核/用户争议时改为 opt-in；DB-IP 许可条款变更时更换数据源（IP2Location LITE 等备选）。
