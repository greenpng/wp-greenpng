# 00. 项目章程 (Project Charter)

> **状态**：已批准　**批准方式**：用户四项关键决策（见 §6）+ 2026-09-09 八项决策（ADR-0007）
> **本文件回答**：greenpng 是什么、不做什么、做到什么程度算成功。

---

## 1. 一句话定位

**greenpng 是一款免费开源的 WordPress 一体化运营套件：让独立站长看清真实访客、挡住恶意流量、搞清广告费去向、识别高价值客户——全部数据留在站长自己的数据库里。**

## 2. 目标用户

- 使用 WordPress + WooCommerce 的独立站站长 / 小型电商运营者
- 投放 Google / Meta / TikTok 广告，受困于虚假流量与归因失真的营销人员
- 注重数据主权、不愿把访客数据交给第三方 SaaS 的站点所有者

## 3. 五大业务域（范围）

| 域 | 核心价值 | 代表能力 |
| :--- | :--- | :--- |
| **流量安全风控** | 看清并挡住假访客 | UA/规则反爬（CrawlerDetect 种子引擎）、客户端安全探针（RPA 识别）、FCrDNS 爬虫验证、IP/CIDR 封禁与白名单、蜜罐（含时间差）、Blackhole 陷阱、登录保护、浪涌折叠日志 |
| **营销归因** | 搞清每分广告费的去向 | 5 维 UTM + 点击 ID 捕获、30 天第一方 cookie 跨天归因、5 种本地归因模型、CAPI 服务端回传（opt-in） |
| **转化漏斗** | 看清每一步流失 | 漏斗步骤状态机、流失率（CSS 阶梯图）、转化目标、A/B 测试（Z 检验，v1.0）、弃购捕获（opt-in） |
| **行为与 CRM 评分** | 识别高价值客户 | 停留/滚动/怒点、线索评分（含风控结论联动）、RFM 分层、标签、用户质量分 |
| **生态集成** | 不打断站长现有工具链 | WooCommerce + 主流表单插件桥接、通用 Webhook、第三方分析回传、开放适配器 API |

## 4. 非目标（明确不做）

以下条目是**经过评估后的主动放弃**，不是"还没做"：

- ❌ **付费版 / Pro 版 / License / 云端服务 / 跨站情报网络** —— 永久非目标（ADR-0002）
- ❌ **设备指纹用于营销画像**（跨站标识符、可逆识别个人的指纹数据入库/出网）—— 安全用途的**有限自动化信号检测**（`navigator.webdriver`、渲染器类别等，无持久标识符、无指纹原始串）依 ADR-0007 以合法利益默认开启、可一键关闭
- ❌ **会话回放 / 录屏** —— 最高隐私风险，不做
- ❌ **Google Ads 离线转化 API** —— 需 Google 审批的开发者令牌，免费自托管插件无法交付（见 `07-third-party-apis.md`）
- ❌ **WAF 级别的深度包检测** —— 那是 Wordfence 的产品类别；greenpng 做"流量质量与基础防护"，不做全功能防火墙
- ❌ **对具体插件的硬编码 / 样本库式适配** —— 集成只走目标插件公开 Hook/API + 回退告警（ADR-0007 铁律 6）
- ❌ **"兼容 156 款插件"的数量宣称** —— 只承诺实测过的适配器 + 公开适配器 API
- ❌ **多站点网络（Multisite）专有功能** —— v1 保证在 Multisite 下不报错，不提供网络级聚合

## 5. 成功标准

| 维度 | 标准 |
| :--- | :--- |
| 合规 | 通过 WordPress.org 插件目录审核（清单 `08` 全绿） |
| 性能 | 满足 `09-performance-budgets.md` 全部分层预算，在共享主机（无对象缓存）实测 |
| 质量 | PHPStan/PHPCS 零错误；核心域单元测试覆盖率 ≥ 70%；激活/停用/卸载幂等 |
| 诚实 | 文档与 UI 中的每个数字都可复现测量；每个"支持 X"声明都有对应测试 |
| 安全 | 无 S1-S6 级别缺陷（见 `01` §3.1）；第三方安全审计零高危 |
| 兼容 | PHP 7.4~8.5+ / WP 6.0~7.1+ 双向兼容（ADR-0007）；常用插件共存矩阵实测 |
