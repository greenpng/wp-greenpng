## 一、 战略定位统一：聚焦 100% 纯免费开源插件，无需考虑商业化

根据最新明确的项目定位：
> **本项目坚定定位于 WordPress.org 官方插件目录的 100% 纯免费、开源、无 Pro、无付费锁定、无商业授权限制的旗舰运营套件。**  
> 我们无需纠结商业变现与云端订阅，**核心精力全部聚焦于如何在纯本地、纯免费的前提下，将功能做到极致、将老旧与现代环境（PHP 7.4~8.5+、WP 6.0~7.1+）的双向兼容做到极致，真正实现站长的核心运营诉求**！

在此前提下，同事在 `docs/12-roadmap-free-v1.md` 中做出的四期功能推迟安排，存在严重的**“核心价值过度延宕、首发版本能力空心化”**问题，亟需重构。

## 二、 现状问题解剖：路线图倒置导致免费版核心价值推迟

### 1. 同事原版路线图缺陷（docs/12 现状）：
- **v1.0**：核心底座 + 保守流量安全（仅静态 UA 正则）+ 基础归因（但因每日旋转盐导致跨天失效）；
  - **砍掉/延期**：客户端环境探针、CAPI 出网、A/B 测试、漏斗流失图、CRM 用户质量分联动。
- **v1.1**：才开始引入客户端探针与 CAPI；
- **v1.2**：才开始引入 A/B 测试与弃购挽回；
- **v1.3**：才考虑设备信号。

### 2. 为什么站长无法接受？
- 独立站长安装本插件的核心诉求非常纯粹：
  1. **花钱投广告，要挡住虚假点击与 RPA 爬虫**；
  2. **要看清真实的广告来源归因与流失漏斗**；
  3. **要测试哪个广告落地页转化率高（A/B 测试）**。
- 如果 v1.0 按照同事的规划发布，站长安装后发现：既抓不住真实的无头浏览器和 RPA，又无法进行落地页 A/B 测试，漏斗甚至连个直观图表都没有。站长会立即认定插件功能简陋而卸载。

## 三、 汲取同类开源插件精华，重构“三期递进”落地路线图

基于 `/Users/macos/wp-plug/` 目录下 226 个同类插件的成功实践（见 `PEER-01` 与 `PEER-02`），我们为**纯免费版**重构出更合理、更健壮的三期演进方案：

```
┌─────────────────────────────────────────────────────────────────────────┐
│              纯免费版路线图重构 (Free-Only Excellence Roadmap)           │
└─────────────────────────────────────────────────────────────────────────┘

【v1.0 真正立足版：四大支柱首发闭环】
  ├─ 1. 兼容底座：PHP 7.4 ~ 8.5+ 严格无警告运行 + WP 6.0 ~ 7.1+ 双向兼容
  ├─ 2. 独立设置中心：顶级菜单下拥有清晰的 Settings 入口，告别隐匿
  ├─ 3. RPA 与安全拦截：
  │    • 整合 JayBizzle 爬虫正则引擎（纯本地 <0.2ms）
  │    • 引入合规客户端合法利益探针（识别 navigator.webdriver/WebGL 虚拟机）
  │    • Antispam Bee 式无感隐形蜜罐（Zero CAPTCHA）
  │    • 浪涌折叠日志原子持久化（ON DUPLICATE KEY UPDATE 杜绝并发崩溃）
  ├─ 4. 跨天营销归因闭环：
  │    • 借鉴 HandL UTM Grabber：30 天加密第一方 Cookie（解绑每日旋转盐）
  │    • 5 种归因模型（First/Last/Linear/Position/Time-decay）本地计算
  │    • WooCommerce 双轨（经典 + HPOS + Blocks Store API）转化幂等绑定
  ├─ 5. 开箱即用体验：预置 CC BY 4.0 免费 DB-IP Lite 国家离线库，首发大盘即见全球分布
  └─ 6. 异步队列弹性适配：运行时嗅探 Action Scheduler，未安装平滑降级 WP-Cron

【v1.1 增长增强版：转化提效与生态打通】
  ├─ 1. 落地页 A/B 测试：原生 URL 参数切流与短码分流 + 纯 PHP 双比例 Z 检验算法
  ├─ 2. 原生阶梯漏斗流失图：无需庞大 JS，纯 CSS/SVG 渲染清晰的各步骤转化率
  ├─ 3. 广告平台 CAPI 服务端回传：Meta CAPI + GA4 MP（带 event_id 双端去重与重试队列）
  ├─ 4. CRM 用户质量与风控联动：风控识别出的 RPA 自动将线索分清零并打标 sys:bot
  └─ 5. 电商弃购挽回：失焦邮箱捕获 + 令牌核销 + 防重复发信机制

【v1.2 开放互联版：全生态插件互通】
  ├─ 1. 开放适配器 API：提供 Adapter_Interface 允许站长轻松适配任意第三方表单或插件
  ├─ 2. 出网 Webhook 增强：集成飞书、企业微信、钉钉、Slack 本地消息模板
  └─ 3. 动态事件嗅探器：允许站长在后台零代码监听任意 WordPress 钩子并生成事件流
```
